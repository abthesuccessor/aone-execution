# Graph Engineering workbench

Approved on 2026-09-12: implement the user's minimal VS Code style AI engineering IDE refinement.

The graph and selected unit of work dominate. A compact activity bar, collapsible Explorer, tabbed editor, optional AI sidebar, bottom tools panel, and status bar form the workspace. One neutral dark theme with restrained cyan accent, system UI text and monospace code. Preserve Tauri, React, the local engine, revision pins and observed trace evidence.

A node can be configured, discussed, refined, fact-checked, developed and executed. AI suggestions are reviewed before Apply; execution remains a separate action. Default agents, skills and prompts are editable versioned catalogs. N:M semantic relationships are distinct from execution ordering. Checkpoint pause must never imply that an in-flight process has stopped.

The user's compact IDE request overrides marketing spacing and metric-card/dashboard recipes. Product completeness, keyboard access, readable contrast and honest state take priority. No decorative motion, gradients or display typography. Main workflow: configure provider, chat, create/refine nodes, connect many-to-many, customize catalog, fact-check, develop, pause/resume, inspect evidence after reopen.
